# 綠波通勤

永和 ⇄ 台北松江路的機車通勤導航網頁。騎車時大字顯示下一個號誌路口、距離和轉彎，並從你每天的實際騎乘中自動學習每個路口的號誌週期與你的車速，用來預測燈號、估算抵達時間。

網址：<https://ken5170696.github.io/Super-speed-Commuters/>

## 怎麼用

1. 用 iPhone 的 Safari 打開上面的網址，按「分享 › 加入主畫面」，之後從主畫面開啟，畫面會像 App 一樣全螢幕。
2. 第一次使用時到「紀錄」分頁，站在家門口按「把目前位置設為家」，到公司時再設定「公司」。這兩個位置只存在你的手機裡。
3. 要出門時在「出發」分頁看各路線的預估時間，選好路線後按「開始導航」，把手機放上手機架。

## 騎乘畫面

- **下一個號誌**：距離、路口名稱，以及燈號預測。
  - 學會這個路口的週期以前，會顯示「號誌未知」，以及你過去在這裡停過幾次、平均等幾秒。
  - 學會以後，會提示「綠燈可過，保持」「收油到 xx km/h，抵達時剛好轉綠」或「會遇紅燈，約等 xx 秒」。
- **下一個轉彎**：包括可能需要兩段式左轉的路口。
- **預計抵達時間**：上班時段會顯示會不會遲到。
- **語音提示**：轉彎前、接近號誌時會唸出來，騎車時不用看手機。

## 自動蒐集的資料

- **GPS 軌跡**：導航時每秒記錄一次，抵達「家」或「公司」附近會自動結束並存檔。
- **號誌觀察**：每次在號誌前停下再起步，起步的時刻會記成一次「綠燈亮」的觀察。同一個路口、同一時段（早上或傍晚）累積 4 次以上，就會推算出號誌週期。停在路口時也可以按「綠燈亮」手動補一筆。
- **你的車速**：從錄到的軌跡算出你在每 100 公尺路段的實際行進速度，到站時間和燈號預測都用這個速度剖面。還沒有軌跡以前，會先用過去 Google 時間軸紀錄校正過的模型估計。

## 匯出到分析網頁

到「紀錄 › 匯出 GPX」，把檔案拖進分析網頁的「GPS 紀錄分析」，就能看到每個路口的停等統計。「備份全部資料」可以搬到另一支手機。

## 限制

- iPhone 的網頁在螢幕關掉或切到其他 App 時會停止定位。導航時會請求螢幕保持開啟，請不要鎖定螢幕。
- 號誌週期是從你的觀察推算的。感應式號誌或會依車流調整的路口，推算結果會不穩定，畫面上會顯示吻合度。
- 所有資料都存在手機瀏覽器裡。清除 Safari 網站資料會一併刪除，請定期「備份全部資料」。

## 隱私

這個 repo 是公開的，所以路線資料裡**沒有**家和公司的位置：每條路線靠近家的一端裁掉 500 公尺，靠近公司的一端裁掉 300 公尺。家、公司、軌跡和號誌觀察只存在你的手機上，不會上傳到任何地方。

## 開發說明

純靜態網頁，沒有建置步驟：`index.html`、`style.css`、`app.js`、`sw.js`（離線快取）、`data/routes.json`。

`data/routes.json` 是用 OpenStreetMap 路網（2026 年 11 月）計算的 8 條候選路線（上下班各 4 條），計算時不走高架、快速道路和禁行機車路段。內容包括每條路線沿途的號誌、轉彎與路段名稱。座標是以 `proj` 為原點的公尺座標。

本機測試：

```bash
python3 -m http.server 8000
```

然後打開 <http://localhost:8000>。瀏覽器只允許 `localhost` 或 HTTPS 頁面使用定位。
