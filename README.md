# 綠波通勤

永和 ⇄ 台北松江路的機車通勤導航網頁。它會：

- **地圖即時導航**：向量地圖，放大不會模糊；地圖隨行進方向旋轉、傾斜成 3D 視角；轉彎提示加語音。走了不同的路，會依你目前的位置自動重新規劃。
- **學習你的習慣**：從你騎過的軌跡，學會你常走哪些路、每段路實際騎多快，以及每個路口的號誌週期。

網址：<https://ken5170696.github.io/Super-speed-Commuters/>

## 開始使用

1. 用 iPhone 的 Safari 打開網址，按「分享 › 加入主畫面」。
2. 第一次打開時按「在地圖上設定」，點地圖放下「家」和「公司」的圖釘，可以拖曳微調。這兩個位置只存在你的手機裡。
3. 「出發」分頁會列出候選路線和預估時間。按「開始導航」後，把手機放上手機架。

**我的地點**：除了家和公司，可以再加幾個常去的地點，例如「車庫」、「朋友車行」。

- 「出發」頁上方可以選上班從哪裡出發、下班回到哪裡。沒選的話，會用你在這個星期幾最常去的地點。
- 導航中可以按「往 ○○ ▾」切換目的地。
- 在任何一個地點停下約 10 秒，都會自動結束並記錄成「到○○」。
- 「比平常快／慢」只會跟到同一個地點的紀錄比較。

如果勾選「偵測到你在騎車就自動開始」，只要網頁開著，車速超過約 16 km/h 時就會自動開始導航和記錄。

## 導航中

- **上方綠色橫條**：下一個轉彎的距離、方向和道路名稱。轉彎前約 300 公尺和 60 公尺時會語音提示。
- **號誌卡**：下一個號誌路口的名稱和距離。學會這個路口的週期以後，會提示「綠燈可過，保持」「收油到 xx km/h 免停」或「紅燈，約等 xx 秒」。
- **走別條路**：離開規劃路線約 30 公尺以上，連續 3 次定位都一樣，就會從你目前的位置和行進方向重新規劃。規劃時會偏好你常走的路。
- **下方資訊**：目前車速、預計抵達時間，上班時還會顯示會不會遲到。
- **結束**：抵達家或公司附近停下約 10 秒，會自動結束並存檔。

## 即時路況（免費、免註冊）

網頁每分鐘直接讀取台北市交通管制工程處公開的「道路速率」資料（[GetVD.xml.gz](https://tcgbusfs.blob.core.windows.net/blobtisv/GetVD.xml.gz)，政府資料開放授權）。

- **怎麼用在路線上**：`data/vd_map.json` 把各偵測路段對應到路網。每個偵測器的車速也套用到同一條路前後各約 300 公尺。
- **出發前**：每條候選路線會顯示壅塞或稍慢的長度，在同一時段累積幾天資料後，還會顯示「比平常慢／快幾 %」。預估時間會依即時車速調整。
- **導航中**：每分鐘依即時路況檢查一次。如果另一條路能快 1.5 分鐘以上，會自動改道並語音告知。地圖上的路線會用綠、黃、紅標出路況。
- **涵蓋範圍**：只有台北市的主要道路有偵測器，永和段沒有公開的即時資料。

重建路段對應：

```bash
node tools/build_vd_map.js
```

## 官方號誌時制（台北市，免費、免申請）

臺北市政府交通局每天公開各路口的號誌時制計畫（[資料集](https://data.gov.tw/dataset/145720)），內容包括：

- 每個時段跑哪一套時制（平日與假日不同）
- 每套時制的週期、時差（offset），以及各時相的綠燈、黃燈、全紅秒數

`data/signal_plans.json` 由 `tools/build_signal_plans.py` 產生。原始資料只有路口名稱，沒有座標，所以腳本會用路口的兩條路名，在路網上找出它們的交會點，目前對應到全台北市 2,828 個路口中的 1,887 個（約 67%）。

**使用方式**

1. 騎乘時，依你抵達的時刻查出當時的時制，以「午夜為基準、加上時差」推算各時相的綠燈時段。
2. 依你的行進方向，猜測哪個時相是你的綠燈，顯示為「官方時制（行向待驗證）」。
3. 你在這個路口停下再起步 2 次以後，就會比對出你的時相和時鐘誤差，改顯示「已驗證」。
4. 驗證過的路口夠多以後，時鐘誤差也會套用到還沒驗證的路口。

新北市（永和段）沒有公開時制，仍然靠你的停等學習。

GitHub Actions 每週一凌晨 03:17（台北時間）自動更新一次（`.github/workflows/signal-plans.yml`），只有時制真的改變時才會提交。也可以在 repo 的 Actions 分頁手動執行「Refresh signal timing plans」。

手動更新（約 60 MB 原始檔，會自動下載）：

```bash
python3 tools/build_signal_plans.py
```

## 蒐集的資料

導航時每次 GPS 更新（iPhone 約每秒一次）都會記下這些資料：

- 時間、經緯度、速度、方向、精確度、海拔。
- 加速度感測器每秒的最大值，用來判斷起步和煞車（需要允許「動作與方向」）。

軌跡存在手機的 IndexedDB，每 20 秒寫入一次，就算網頁中途被關掉也不會整趟遺失。

從軌跡自動學習的內容：

| 學什麼 | 怎麼學 |
|---|---|
| 你常走的路 | 把每條軌跡對應到路網，統計每段路走過幾次，規劃時偏好這些路 |
| 每段路的車速 | 每段路行進中的速度中位數，用來估算抵達時間 |
| 號誌週期 | 在號誌前停下再起步的時刻，就是一次「綠燈亮」。同一路口、同一時段累積 4 次以上就推算週期 |
| 每個路口平均等多久 | 停等秒數除以經過次數 |

## 紀錄

「紀錄」分頁可以看每一趟的詳細資料：

- **地圖軌跡**：依速度上色，停下的地方標出停等秒數。
- **統計**：總時間、距離、行駛時間、停止時間、停下次數、平均速度和最高速度。
- **速度圖**：速度和時間的關係，停等時段會標成紅色。
- **號誌停等**：每次停在哪個路口、停了幾秒。
- **經過的道路**：每條路的距離、時間和平均速度。

每一趟都能匯出 GPX，也可以「備份全部資料」搬到另一支手機。Google 時間軸匯出的 JSON 可以匯入，但只會有出發和抵達時間，沒有詳細軌跡。

## 限制

- iPhone 的網頁在螢幕關掉或切到其他 App 時會停止定位。導航時會請求螢幕保持開啟，請不要鎖定螢幕。
- 路網涵蓋整個台北市與新北市核心區（板橋、三重、新莊、中永和、新店等；約北緯 24.93–25.21、東經 121.40–121.67）。超出範圍無法規劃路線。
- 地圖底圖需要網路（[OpenFreeMap](https://openfreemap.org/) 免費向量圖磚，不需金鑰）。路網和規劃都在手機上計算。

## 隱私

這個 repo 是公開的，但裡面只有公開的路網資料（OpenStreetMap）。家、公司、軌跡和號誌觀察只存在你的手機上，不會上傳到任何地方。

## 開發說明

純靜態網頁，沒有建置步驟：

| 檔案 | 內容 |
|---|---|
| `index.html`、`style.css` | 介面 |
| `app.js` | 導航、學習、紀錄、匯入匯出 |
| `js/graph.js` | 路網載入、A* 路徑規劃（含禁止轉向）、軌跡對應路網、路線描述 |
| `data/graph.json` | 機車可行駛的路網：不含高架、快速道路與禁行機車路段，壓縮成路口節點加路段形狀 |
| `sw.js` | 離線快取 |

路網由 GitHub Actions 的「Build road network」工作建立（每月 2 日自動執行，也可以手動執行）。它會下載 Geofabrik 的台灣 OpenStreetMap 資料，產生路網，再重新對應即時路況路段與官方號誌時制。

在本機重建：

```bash
python3 tools/build_graph.py --pbf taiwan-latest.osm.pbf --bbox 121.40,24.93,121.67,25.21
node tools/build_vd_map.js
python3 tools/build_signal_plans.py
```

本機測試（瀏覽器只允許 localhost 或 HTTPS 頁面定位）：

```bash
python3 -m http.server 8000
```
