# 綠波通勤

永和 ⇄ 台北松江路的機車通勤導航網頁。它會：

- **地圖即時導航**：轉彎提示加語音。走了不同的路，會依你目前的位置自動重新規劃。
- **學習你的習慣**：從你騎過的軌跡，學會你常走哪些路、每段路實際騎多快，以及每個路口的號誌週期。

網址：<https://ken5170696.github.io/Super-speed-Commuters/>

## 開始使用

1. 用 iPhone 的 Safari 打開網址，按「分享 › 加入主畫面」。
2. 第一次打開時按「在地圖上設定」，點地圖放下「家」和「公司」的圖釘，可以拖曳微調。這兩個位置只存在你的手機裡。
3. 「出發」分頁會列出候選路線和預估時間。按「開始導航」後，把手機放上手機架。

如果勾選「偵測到你在騎車就自動開始」，只要網頁開著，車速超過約 16 km/h 時就會自動開始導航和記錄。

## 導航中

- **上方綠色橫條**：下一個轉彎的距離、方向和道路名稱。轉彎前約 300 公尺和 60 公尺時會語音提示。
- **號誌卡**：下一個號誌路口的名稱和距離。學會這個路口的週期以後，會提示「綠燈可過，保持」「收油到 xx km/h 免停」或「紅燈，約等 xx 秒」。
- **走別條路**：離開規劃路線約 30 公尺以上，連續 3 次定位都一樣，就會從你目前的位置和行進方向重新規劃。規劃時會偏好你常走的路。
- **下方資訊**：目前車速、預計抵達時間，上班時還會顯示會不會遲到。
- **結束**：抵達家或公司附近停下約 10 秒，會自動結束並存檔。

## 蒐集的資料

導航時每次 GPS 更新（iPhone 約每秒一次）都會記下這些資料：

- 時間、經緯度、速度、方向、精確度、海拔。
- 加速度感測器每秒的最大值，用來判斷起步和煞車（需要允許「動作與方向」）。

軌跡存在手機的 IndexedDB，每 20 秒寫入一次，就算網頁中途被關掉也不會整趟遺失。

從軌跡自動學習的內容：

| 學什麼 | 怎麼學 |
|---|---|
| 你常走的路 | 把每條軌跡對應到路網，統計每段路走過幾次，規劃時偏好這些路 |
| 每段路的車速 | 每段路行進中的速度中位數，用來估算抵達時間 |
| 號誌週期 | 在號誌前停下再起步的時刻，就是一次「綠燈亮」。同一路口、同一時段累積 4 次以上就推算週期 |
| 每個路口平均等多久 | 停等秒數除以經過次數 |

## 紀錄

「紀錄」分頁可以看每一趟的詳細資料：

- **地圖軌跡**：依速度上色，停下的地方標出停等秒數。
- **統計**：總時間、距離、行駛時間、停止時間、停下次數、平均速度和最高速度。
- **速度圖**：速度和時間的關係，停等時段會標成紅色。
- **號誌停等**：每次停在哪個路口、停了幾秒。
- **經過的道路**：每條路的距離、時間和平均速度。

每一趟都能匯出 GPX，也可以「備份全部資料」搬到另一支手機。Google 時間軸匯出的 JSON 可以匯入，但只會有出發和抵達時間，沒有詳細軌跡。

## 限制

- iPhone 的網頁在螢幕關掉或切到其他 App 時會停止定位。導航時會請求螢幕保持開啟，請不要鎖定螢幕。
- 路網涵蓋永和到中山區（約北緯 24.992–25.054、東經 121.506–121.548）。超出範圍無法規劃路線。
- 地圖底圖需要網路。路網和規劃都在手機上計算。

## 隱私

這個 repo 是公開的，但裡面只有公開的路網資料（OpenStreetMap）。家、公司、軌跡和號誌觀察只存在你的手機上，不會上傳到任何地方。

## 開發說明

純靜態網頁，沒有建置步驟：

| 檔案 | 內容 |
|---|---|
| `index.html`、`style.css` | 介面 |
| `app.js` | 導航、學習、紀錄、匯入匯出 |
| `js/graph.js` | 路網載入、A* 路徑規劃（含禁止轉向）、軌跡對應路網、路線描述 |
| `data/graph.json` | 機車可行駛的路網：不含高架、快速道路與禁行機車路段，壓縮成路口節點加路段形狀 |
| `sw.js` | 離線快取 |

重建路網（會從 api.openstreetmap.org 下載資料）：

```bash
python3 tools/build_graph.py --tiles /path/to/osm-tiles --out data/graph.json
```

本機測試（瀏覽器只允許 localhost 或 HTTPS 頁面定位）：

```bash
python3 -m http.server 8000
```
